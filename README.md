# One Word for the Boss

One word that describes the boss — a single-word entry for the make.fun
bounty "One Word for the Boss". The program writes exactly one word to
`/output/entry.txt`: no phrase, no caption, no explanation. The word is
the whole entry, and it has to land on its own.

## The entry

The boss is the bottleneck: every decision, approval, and reply has to
pass through one person, so all the work queues up behind them. It is
funny because it is true in every office, kitchen, and warehouse — and
it is a word a colleague would actually repeat at lunch.

## Run

Requires Node 22 or later. No dependencies, no network, no configuration:

```sh
node main.ts
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes
the entry word to `entry.txt` inside it.
